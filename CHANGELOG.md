# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [1.2.3] - 2026-08-09

### Added
- Daily maintenance commit for streak tracking
- Enhanced security checks in CI/CD pipeline
- Improved documentation for API endpoints

### Fixed
- Rate limiting behavior on redirect endpoints
- Cache invalidation for expired URLs

### Changed
- Updated dependencies to latest security patches

## [1.2.2] - 2026-08-01

### Added
- Analytics dashboard for URL tracking
- Support for custom URL slugs
- Rate limiting per IP address

### Fixed
- Database connection pooling issues
- URL validation edge cases

## [1.2.1] - 2026-07-15

### Added
- Basic authentication for API
- Logging infrastructure

### Fixed
- Redirect loop prevention

## [1.2.0] - 2026-07-01

### Added
- RESTful API for URL shortening
- User authentication system

## [1.1.0] - 2026-06-01

### Added
- Database persistence layer
- URL expiration feature

## [1.0.0] - 2026-05-01

### Added
- Initial release
- Basic URL shortening functionality
- HTML frontend
